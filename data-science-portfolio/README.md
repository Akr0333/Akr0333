# Data Science Portfolio

A collection of practical Data Science and Machine Learning projects.

## Projects

### 1. Customer Churn Prediction
Predict whether a customer is likely to leave a subscription service using classification models.

**Skills:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, EDA, Logistic Regression, Random Forest, model evaluation.

### 2. Credit Card Fraud Detection
Identify potentially fraudulent transactions using machine learning and imbalanced-class techniques.

**Skills:** EDA, preprocessing, class imbalance, Logistic Regression, Random Forest, precision, recall, F1-score, ROC-AUC.

### 3. Sales Data Analysis
Analyse sales transactions to discover revenue trends, best-selling products, regional performance and customer patterns.

**Skills:** Pandas, NumPy, data cleaning, aggregation, visualisation and business insights.

## Goal
Build a practical portfolio demonstrating the complete data science workflow: data cleaning → exploration → visualisation → modelling → evaluation → insights.
